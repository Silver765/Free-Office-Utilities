# Free Office Utilities

A collection of free, offline desktop tools for everyday office work.

| App | What it is |
|---|---|
| [Silver PDF Pro](silver-pdf-pro/) | View, annotate, sign, OCR, organize and edit PDFs — Windows, macOS (Intel & Apple Silicon) and Linux |

Installers for each app are built by GitHub Actions — see the **Actions** tab, or the **Releases** page for tagged versions.
